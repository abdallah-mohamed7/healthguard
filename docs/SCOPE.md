# HealthGuard: Approved Scope Specification

## Pipeline
1. Health Profile: User demographics and baseline metrics
2. Lab Report OCR: Upload photo/PDF, extract tests, ranges, values
3. Timeline & Analytics: Historical charts, deterministic risk flags
4. Screening Engine: Automated guideline-based reminders
5. AI Assistant: LLM explanations with hard clinical guardrails
6. Deployment & Ops: Docker, automated tests, cloud hosting

## Out of Scope
- Autonomous clinical diagnosis
- Direct EHR hospital integrations
