# HealthGuard: Problem Definition

## Problem
Preventable chronic conditions worsen silently due to inconsistent tracking, siloed vitals data, and lack of accessible early risk detection.

## Solution
HealthGuard is a preventive health platform (Web + Android) combining proactive biometric logging, automated risk scoring, and verified AI triage guidance.

## Scope Boundaries
- Web & Mobile vitals logging and risk dashboard.
- Flask + MongoDB backend for secure vitals persistence.
- Gemini + Groq triage engine grounded in clinical guidelines via RAG.
